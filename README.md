# Kubxr — Kubernetes on Android (archived)

> **Archived: merged into Linxr.** Kubernetes on Android now runs as the k3s recipe in the [Linxr](https://github.com/AI2TH/Linxr) Marketplace; manage it with [Vizxr](https://github.com/AI2TH/Vizxr).

Kubxr was a standalone Android app that ran a Kubernetes node in a QEMU virtual machine, without root.
